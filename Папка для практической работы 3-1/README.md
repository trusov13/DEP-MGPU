## 🧩 Краткое описание проекта  
Проект представляет собой разработку интерактивного дашборда в **Yandex DataLens** по теме *«Коммерческий анализ данных по результатам маркетинговых исследований»*.  
На основе предоставленного набора данных проведён анализ **доли рынка**, **потребительских предпочтений** и **конкурентных позиций брендов** (сегменты: Base, Game, Elite).  
Дашборд позволяет в наглядной форме изучать структуру рынка, поведение потребителей, динамику конверсий и сравнивать эффективность брендов в различных сегментах. Ключевые метрики включают новые визиты (21 914), выручку от конверсий (278 667 ₽), общую конверсию (6,94%) и распределение по каналам трафика.  

📊 [Посмотреть дашборд в Yandex DataLens](https://datalens.yandex/oyd4hvj6pduu9)

## 🎯 Цели проекта  
- Преобразовать исходные маркетинговые данные в информативные бизнес-метрики (KPI: конверсия, узнаваемость, бюджеты).  
- Реализовать интерактивный дашборд с фильтрами по датам и сегментам, отражающий ключевые показатели и взаимосвязи между ними (тренды, распределения, корреляции).  
- Выявить закономерности потребительских предпочтений (линейные графики по сегментам), позиции брендов на рынке (scatter plot эффективность vs. бюджет) и зависимости (пироговая диаграмма долей конверсий).  
- Продемонстрировать применение инструментов **Business Intelligence** для поддержки маркетинговых решений, включая оптимизацию бюджетов и каналов трафика.  

## 📈 Ключевые визуализации и insights  
- **KPI-блок**: Отображает новые визиты, выручку, общую конверсию (6,94%) и микс каналов (70 авторов).  
- **Тренды узнаваемости**: Линейный график по сегментам (Base — стабильный, Game — волатильный, Elite — растущий).  
- **Доля конверсий**: Круговая диаграмма (контекстная реклама ~40%, социальные сети ~35%, платный трафик ~25%).  
- **Конверсия по каналам**: Столбчатая диаграмма по дням, подчёркивающая лидерство платного трафика.  
- **Эффективность vs. бюджет**: Scatter plot, показывающий убывающую отдачу при бюджете >30k ₽.  
- **Распределение расходов**: Столбчатая диаграмма по дням, коррелирующая с пиками конверсий.  

*Инсайт*: Elite-сегмент лидирует по узнаваемости и конверсии; рекомендуется перераспределить бюджеты в контекстную рекламу для баланса.

## 🧠 Итоговые выводы  
- BI-инструменты, такие как Yandex DataLens, позволяют эффективно визуализировать и анализировать результаты маркетинговых исследований, превращая сырые данные в actionable insights.  
- Дашборд помогает быстро выявлять лидеров (Elite) и отстающих брендов (Base), а также понимать структуру рыночных сегментов и каналов трафика.  
- Анализ подтвердил зависимость между узнаваемостью бренда, его восприятием, конверсией и рыночной долей (e.g., рост Elite коррелирует с +20% конверсии).  
- Разработанное решение может использоваться бизнес-аналитиками и маркетологами для принятия стратегических решений по позиционированию бренда, распределению рекламных бюджетов и A/B-тестированию кампаний. Рекомендуется добавить прогнозные модели для будущих трендов.
