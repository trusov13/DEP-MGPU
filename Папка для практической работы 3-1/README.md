## 🧩 Краткое описание проекта  
Проект представляет собой разработку интерактивного дашборда в **Yandex DataLens** по теме *«Анализ результатов маркетинговых исследований»*.  
На основе предоставленного набора данных проведён анализ **доли рынка**, **потребительских предпочтений** и **конкурентных позиций брендов**.  
Дашборд позволяет в наглядной форме изучать структуру рынка, поведение потребителей и сравнивать эффективность брендов в различных сегментах.  

📊 [Посмотреть дашборд в Yandex DataLens](https://datalens.yandex/oyd4hvj6pduu9)



## 🎯 Цели проекта  
- Преобразовать исходные маркетинговые данные в информативные бизнес-метрики.  
- Реализовать интерактивный дашборд, отражающий ключевые показатели и взаимосвязи между ними (тренды, распределения, корреляции).  
- Выявить закономерности потребительских предпочтений.  
- Продемонстрировать применение инструментов **Business Intelligence** для поддержки маркетинговых решений, включая оптимизацию бюджетов и каналов трафика. 



## 🧠 Итоговые выводы  
- BI-инструменты позволяют эффективно визуализировать и анализировать результаты маркетинговых исследований.  
- Дашборд помогает быстро выявлять лидеров и отстающих, а также понимать структуру рыночных сегментов.  
- Анализ подтвердил зависимость между узнаваемостью бренда (сегмента), его восприятием и рыночной долей.  
- Разработанное решение может использоваться бизнес-аналитиками и маркетологами для принятия стратегических решений по позиционированию бренда (сегмента) и распределению рекламных бюджетов.
